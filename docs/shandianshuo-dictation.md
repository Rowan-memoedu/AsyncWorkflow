# 闪电说短按的 Luna 写作路由

适配层复用 `refinement.py` 的决策规则、验证器和凭据读取。写作分支使用允许自然改写、细致分层与全文校订的成稿规则，非写作分支使用独立的深度整理规则，提炼中心意思、清理口语并重组层级。直接向助手提出任务或反馈属于非写作。正文经 Responses API 生成，使用纯 bullet、两空格嵌套与 LaTeX，程序追加唯一的末尾 `- `。

后台录音使用 H1 加 bullet 的格式。闪电说写作分支与后台写作共用独立内容规则，再附加纯 bullet 格式；后台写作只复用公共文件的 H1/bullet 格式，不再叠加旧的最小改写内容约束。闪电说非写作分支使用 `refine-dictation-non-writing.md`，与后台录音、批量录音和视频强结构化共享已验证的内容规则，各自保留原有输出格式。其他强结构化入口不增加写作判断。

正文按最终路由选择模型：写作沿用默认 `refinement_model` / `refinement_reasoning`，非写作可通过 `refinement_non_writing_model` / `refinement_non_writing_reasoning` 单独设置为 `gpt-6.1-sol` / `medium`。当前两条正文路线均使用 `gpt-6.1-sol` / `medium`，决策仍使用 Luna；原始回应、实际模型、推理设置和提示词哈希写入本机收据，缓存身份覆盖两条路线的生成设置。

## 兼容边界

- 不修改闪电说 EXE、WebView、安装资源或内置技能。应用更新不会直接覆盖本项目源码、共享提示词或回环服务。
- 入口为标准 `/v1/chat/completions`，同时支持 JSON 和 SSE，并提供 `/v1/models`；供应商端仍调用官方 Decisions 和 Responses API。
- 当前实现接受单轮纯文本 user 消息，以及从闪电说 0.8.2 原生请求确认的 `ASR 原文：` 包装；只有系统消息同时表明是语音输入整理器时才剥离这一协议前缀。客户端系统提示不传给上游。拒绝多轮对话、工具消息和已识别客户端的未知包装；真实原生录音还须验证完整链路。
- 服务每次请求读取当前配置和提示词；成功缓存绑定决策规则、模型、推理设置及内容/格式规则。修改这些规则后自动使用新的缓存身份，历史正文不重放。
- 不能承诺未来客户端或 API 的任意破坏性更新自动兼容。维护要求是：固定依赖、协议回归、真实原生 Canary 和可恢复配置。发现未知消息结构时明确失败，不猜测原文、不静默降级。

## 本机运行

源码入口为 `async_workflow.dictation_gateway`；端口为 127.0.0.1:43143，只监听回环；随机客户端令牌保存在运行目录的 `dictation/client-token.txt`，与 OpenAI Key 分开。不开 CORS，不记录请求鉴权头。真正的 OpenAI Key 继续只从已配置的外部环境文件或进程环境读取。

复用现有计划任务安装器：

```powershell
.\scripts\install-startup.ps1 -Roles dictation -Start
```

该服务单独运行，不重启录音 runner，不引入新的录音、ASR、桌面输入或归档流程。`GET /health` 可读取服务版本与策略指纹。

## 配置与验收

`scripts/dictation_setup.py prepare` 创建本机客户端令牌，不更改闪电说。

`stage` 只准备兼容供应商的 endpoint、model 和客户端令牌，保存精确范围的旧值；保留当前快速模型与整理级别，用于模型检测。`activate-test` 是原生验收期间的临时切换，使用兼容供应商并保持 strong，让原生整理请求实际进入适配层。原生系统提示不会传给上游，因此不会发生第二次内容整理。脚本通过运行中产品设置 API 将直接说超时设为 30 秒，并回读快速模型、供应商与超时；不能只写配置文件就认证激活。

`enable` 仅在运行目录存在与当前策略匹配的 `acceptance.json` 且 `passed=true` 时执行，关闭协议捕获。验收文件必须同时有工程回归、真实 API、原生短按、最终输入格式的实际证据，不能用后台测试代替原生验证。

脚本通过配置文件准备数据，但应用是否热加载要用原生产品设置接口与 UI 回读确定；写盘成功不代表正在运行的应用已经切换。应用若需要重启，须按用户对正在使用应用的重启确认规则处理。

## 故障与恢复

- 两个上游请求共享 27 秒总期限，单次不自动重试；原生直接说必须明确设置为 30 秒。默认 10 秒会提前取消正常的两阶段请求，不能沿用。取消会取消正在等待的异步请求；已经在服务端开始的计算不保证撤销计费。
- 拒绝、未完成响应、非法格式、未知模型和上游错误不会返回成功正文。失败保存本轮原始转写于运行目录，方便恢复；不发送到其他供应商。
- 内容完整后才交付。SSE 中只包含已验证的正文，不输出路线、概率、推理或半份文本。
- 已成功的相同请求复用带完整性检查的正文缓存。客户端是否会重试、回退原始 ASR 或重复插入，仍要由原生验收确认。
- 恢复命令为 `python scripts/dictation_setup.py restore`；只恢复本适配层保存的供应商、整理设置与超时覆盖。短按/长按快捷键不修改。如果运行中的应用仍使用适配供应商，脚本保留适配令牌及 30 秒超时，标记恢复未完成并返回失败；在原生界面选回原快速供应商后再次执行，才清理兼容配置并关闭快照。这样不会让运行中的适配模型意外退回 10 秒。旧快照缺少超时原值时保留当前值，不猜测原设置。

## 验证与更新维护

1. `python -m pytest -q`：共享规则、协议、JSON/SSE、格式、鉴权、缓存完整性、超时和取消回归。
2. `python scripts/dictation_canary.py`：合成任务、写作、公式和表达性语气词，走实际回环服务及真实上游 API。
3. 原生模型检测与短按：捕获实际消息包装、核对 ASR 原文、源信息、最终输入框纯 bullet/LaTeX/末尾空格和单次插入。
4. 更新闪电说后，先运行只读设置回读及原生 Canary。若客户端仍发出已支持的 schema，服务无需修改；若协议变化，只维护协议解析和响应封装，复用内容规则。通过后再沿用启用状态。

模型连接探测通过不能替代短按从录音到输入的验证，文件或 API 输出通过也不能替代末尾空格在目标输入框中的验证。
